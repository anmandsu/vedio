# Visual Continuity Protocol

## Consistency Stack

1. Accepted reference image.
2. Character / scene / prop bible.
3. Visual fingerprint prompt fragment.
4. Generation prompt.
5. Vision-model review.
6. User feedback.

## Character Consistency

Lock:

- face structure
- hair
- body type
- costume silhouette
- signature prop
- posture/gesture habit
- color relationship

## Scene Consistency

Lock:

- layout
- time of day
- primary light direction
- color palette
- repeated set dressing
- weather/atmosphere
- damage state

## Shot-to-Shot Connection

For every pair, name the connection:

- action
- gaze
- sound
- prop
- emotion
- spatial movement
- contrast

If there is no named connection, the cut is suspect.
