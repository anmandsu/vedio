# Knowledge Source Policy

Use this whenever external film, director, editing, cinematography, production design, sound, or historical knowledge shapes a decision.

## Source Tiers

| Tier | Source Type | Use |
|---|---|---|
| A | Film text, original screenplay, director/craft interview, masterclass, commentary track, production note, museum/archive material | Can anchor rules |
| B | Professional book, academic paper, serious craft analysis, reputable trade publication | Can support rules |
| C | Social posts, short video analysis, forums, casual essays | Use as inspiration or leads |
| D | Model inference | Label as inference only |

## Source Card

```markdown
## Source: <title>

- URL/path:
- Tier:
- Author/speaker:
- Date:
- Department:
- Claim supported:
- Exact evidence or paraphrase:
- Confidence:
- Limits:
```

## Rules

- Do not use unsourced "director style" claims as hard rules.
- Separate "what the source says" from "how we will use it."
- If sources disagree, preserve the tension; do not smooth it away.
- A project may use weak sources temporarily, but the research gap must be logged.
