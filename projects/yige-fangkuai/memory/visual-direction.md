# Visual Direction Memory

- Aspect ratio for generated images: 16:9.
- Overall look: high-end, simple, clean, bright-toned.
- No hanging props.
- No projection effects.
- Design inspiration: Chinese traditional pictographic-character decomposition and reconstruction.
- Scene transformation method: actors physically push, rotate, split, and combine props.
- Core metaphor: Rubik's-cube-like dismantling and recombination.
- Final visual should synthesize into a unified square-character / accepted-meaning effect.
- Keep the world tied to Chinese character culture, dictionary revision, oracle/pictographic forms, and the concept of 方块字.
