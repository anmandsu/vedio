# Feedback 2026-05-08 V2

- The modular blocks are too solid and box-like.
- Need more design sophistication and a lighter high-end object language.
- Next iteration should keep the same minimalist avant-garde composition but refine the modules:
  - thinner frames
  - hollow / open-frame structures
  - layered panels
  - translucent acrylic or pale jade edges
  - precise joinery
  - less heavy cabinet / crate feeling
  - no hanging or projection
