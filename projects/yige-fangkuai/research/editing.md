# Editing And Continuity Research

## Rhythm

The scene flow should feel like a physical algorithm: intake, sort, check, reject, update, recombine, archive.

## Rules

- Cut or transition only when a module changes function: cube becomes queue marker, queue marker becomes card shelf, shelf becomes security gate, gate becomes final glyph.
- Keep the audience oriented by repeating three action verbs: push, rotate, combine.
- For each system mode, preserve a distinct movement rhythm: gentle intake, sharp sorting, cold deletion, obsessive归档, warm final acceptance.
- Use reaction beats after every rule change so the word-persons can humanize the system logic.
- Continuity anchor: cards never become decorative confetti; each card must remain readable as identity/evidence/permission.

## Stage Transition Pattern

1. Actors push blocks into a line: sorting mechanism.
2. Blocks split into lanes: identity-card审核.
3. Blocks rotate into a gate: deletion / modification screening.
4. Blocks scatter into low archive islands: information database.
5. Blocks close into one square composition: final方块字 / acceptance.
