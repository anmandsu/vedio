## Locked User Direction

- Final images and stage visualization should be 16:9.
- Overall style: advanced, simple, clean, bright-toned, culturally literate, not cluttered.
- No hanging props. No projection effects.
- Design inspiration: dismantling and reconstructing Chinese pictographic characters.
- Scene transitions are actor-driven: performers push, rotate, slice, combine, and reassemble modular props.
- Core spatial metaphor: Rubik's-cube-like decomposition and recombination.
- End image should assemble into one unified “白 / 方块字 / 字义被接纳” effect, not a literal tech projection.

## Design Implications

- The stage must read as a clean “Chinese character archive / dictionary system interior,” but built with physical objects instead of screens.
- Use wheeled or hand-carried cube/rectangular modules with visible handholds; actors' labor is part of the choreography.
- The modular objects should create character radicals, oracle-bone strokes, dictionary cards, archive walls, security gates, and final square-character composition.
- Color should stay bright and high-key: warm white, paper white, pale jade, ink gray, cinnabar accents, small gold/bronze touches.
- Ancient writing references should appear as carved/printed marks, relief grooves, edge lines, card labels, and block silhouettes, not as projected images.
