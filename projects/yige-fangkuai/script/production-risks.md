# Production Risks

| Risk | Why It Matters | Later Department Owner |
|---|---|---|
| 系统多模式表演不清 | 系统需要在亲和、暴躁、冷酷、强迫症、人机精确之间快速切换，若层次不清会变成单一夸张角色。 | director / editor-continuity / sound-designer |
| 学术信息台词密度高 | 郭沫若、商承祚、甲骨文、字义演变等信息必须听得懂，否则情感转折会失去根基。 | director / editor-continuity |
| 卡片道具逻辑复杂 | 卡片同时代表字义、身份、证据、归档资格和文明记录，是全剧最重要的可视化规则。 | production-designer / continuity |
| 舞台空间抽象 | “xxx系统运行内部”需要既像后台系统又能容纳字典、屏障、信息库、归档区。 | production-designer / cinematographer |
| 群演调度拥挤 | 开场排队、字义变形、卡片信息库、多个“白”同台容易混乱。 | director / editor-continuity |
| 喜剧和残酷转调 | 小品节奏中有删除、消亡、牺牲的威胁，转调过猛会破坏观众信任。 | director / sound-designer |
| “白”和“大天白亮”的冲突要可辨 | 二者都是“白”字相关义项，视觉和表演必须明确区分，否则学术分歧不成立。 | visual bible / production-designer |
| 终场温情容易口号化 | “智慧、力量、温度”和“他们没有停过”需要落在前文卡片与人类修订劳动上。 | director / sound-designer |
| 占位信息未定 | 剧本中 `xxx系统`、负责修订集体名称等占位会影响最终舞台设定和台词准确性。 | research / script supervisor |
