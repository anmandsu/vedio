# Prop: Radical Components

## Role

Radical components are smaller modular pieces scattered across the stage. They allow actors to recombine the stage into different Chinese characters, making the dictionary system feel alive.

## Design Lock

- Physical floor-based modules only.
- Scale: handheld panels, waist-high frames, and small rolling square units.
- Forms suggest strokes, radicals, boxes, mouth components, roof components, vertical strokes, dots, and crossing bars.
- High-end lightweight material: matte white ribs, translucent pale-jade edges, ink-gray seams, tiny cinnabar seal marks.
- Components should feel like a deconstructed magic cube and a deconstructed Chinese character at the same time.

## Transformation Logic

- Scatter: components lie separated across stage as unresolved information.
- Sort: actors push components into lanes.
- Rotate: one component quarter-turns to become a different radical function.
- Combine: several components form a temporary character.
- Split: the character breaks apart when a definition is rejected.
- Final: selected components assemble into `合`.

## Anti-Patterns

- Printed giant readable radicals everywhere.
- Calligraphy projection.
- Cluttered classroom teaching aid.
- Toy block colors.
- Hanging radicals.
