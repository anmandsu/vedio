# Production Risks (v0)

## High-Risk Elements for AI Generation
- 竖屏短剧人物一致性（沈婉秋/陆之琛 20集跨场景）
- 豪门空间连续性（别墅/婚房/书房/会议室/医院/停车场/仓库/墓地等多地点）
- 现代服化道“土味/网感”的控制（既要短剧爽感又要高级感）
- 动作场面（追逐、挡刀、摔倒、推搡）手部与肢体易崩
- 手机屏幕/偷拍视频/新闻舆论画面易乱（文字、UI）

## Mitigations (draft)
- 先做角色视觉 bible + 指纹；每次生成强制引用角色参考图
- 场景优先锁“3-4个主场景母版”（婚礼、婚房、陆氏办公、医院）再做变体
- 动作镜头尽量拆分：动作前一镜、动作中一镜、动作后一镜（降低单镜复杂度）
