# Production Risks

| Risk | Why It Matters | Later Department Owner |
|---|---|---|
| Character consistency | 林风、小雀、刀哥都有强视觉标签，后续生成必须维持脸、服装、配饰、气质连续 | visual bible / continuity |
| 小雀可见性规则 | 小雀只有林风能看见，镜头调度和群众反应必须始终支持这个规则 | director / editor-continuity |
| 透视眼视觉化 | 九幽透视眼需要同时表现“看穿”和“压迫感反转”，不能只做普通发光眼 | cinematographer / visual bible |
| 赌桌空间连续性 | 三万藏在刀哥左手袖管、林风面前万字清一色、牌山九筒、打手摸刀都需要空间关系清楚 | storyboard-supervisor / editor-continuity |
| 男频爽感节奏 | 第一场必须从濒死压迫快速转入信息优势和反杀悬念，节奏拖慢会损失类型承诺 | director / editor-continuity |
| 角色呈现边界 | 小雀文本含“萝莉”和“略带性感”描述，后续视觉生成应避免未成年性化呈现，保留神明、傲娇、华丽古风和反差萌 | visual bible / production-designer |
| 暴力威胁尺度 | 剁成肉酱、断手、砍刀等是威胁氛围，不应在当前开场过早转成血腥表现 | director / continuity |
| PDF source incompleteness | 当前源材料只有设定和开场片段，若直接进入完整分镜会缺少后续剧情因果 | script / producer |
