# 针锋·针心 - 场景地图

## 场景统计
- **总场景数**：13个场景
- **主要场景**：老绣坊（内景）
- **次要场景**：旧屋（闪回）
- **特殊场景**：AIGC动画段

## 场景分布

### 第一集《拆牌倒计时》

#### 场1 - 内景·老绣坊·清晨
- **时间**：清晨
- **光线**：冷灰色调
- **人物**：林素琴
- **关键动作**：刺绣、失手、摸耳垂
- **情绪**：压抑、不安
- **视觉重点**：极近特写针刺入绣布、丝线摩擦
- **声音设计**：无音乐、细微摩擦声、远处拆迁机械闷响
- **叙事功能**：建立人物、引入危机、视觉隐喻（第一次失手）

#### 场2 - 内景·老绣坊·傍晚
- **时间**：傍晚
- **光线**：低饱和度
- **人物**：林素琴、绣儿（抱孩子）、小伟
- **关键道具**：红色拆牌通知、手机（短视频数据）、电脑（外婆照片）、蜀绣木牌
- **关键动作**：绣儿拍手机、小伟展示AIGC、林素琴拍桌、打女儿
- **情绪**：急促→对抗→爆发
- **冲突**：传统守护 vs 现代传播/技术
- **叙事功能**：冲突最高点、代际断裂

#### 场3 - 内景·绣坊·夜
- **时间**：夜
- **光线**：无灯，只有窗外冷光
- **人物**：林素琴（独自）
- **关键动作**：看木牌、拿针、手停住
- **情绪**：孤独、迷茫
- **叙事功能**：第一集结束，留下悬念

---

### 第二集《福袋·崩裂》

#### 场4 - 内景·绣坊·深夜
- **时间**：深夜
- **光线**：暖黄灯光
- **人物**：绣儿、林素琴
- **关键道具**：旧福袋（外婆遗物）
- **关键台词**："别死守，要传下去"
- **情绪**：柔软、克制
- **叙事功能**：情感转折的触发点

#### 场5 - 内景·旧屋·夜（闪回）
- **时间**：过去
- **光线**：油灯
- **人物**：外婆、小绣儿
- **关键台词**："蜀绣，是一代传一代的"
- **情绪**：温暖、怀旧
- **叙事功能**：建立传承主题、情感铺垫

#### 场6 - 回到现实
- **时间**：深夜
- **人物**：林素琴、小伟
- **关键动作**：小伟连接电脑到屏幕
- **叙事功能**：过渡到AIGC段落

#### 场7 - AIGC动画段
- **形式**：无对白动画
- **内容**：
  - 骨针穿布（商周）
  - 汉代织锦
  - 唐宫绣衣
  - 宋代写意
  - 明清绣坊
  - 外婆的手 → 林素琴的手 → 数字重构 → 绣儿发布
- **叙事功能**：展现蜀绣历史、技术与传统的对话
- **制作难点**：风格统一、历史准确性、情感连贯

#### 场8 - 灯亮
- **时间**：深夜
- **光线**：屏幕光 + 室内灯
- **人物**：林素琴、小伟、绣儿
- **关键道具**：福袋、散落的针
- **关键动作**：看屏幕、针盒掉落、捡不起针、崩溃
- **关键台词**："好看，但那不是蜀绣" / "我守了一辈子针……是不是守错了"
- **情绪**：抗拒→动摇→崩溃（情绪最低点）
- **叙事功能**：人物弧光转折点

### 第三集《一针新生》

#### 场9 - 内景·清晨
- **时间**：清晨
- **光线**：天光微亮
- **人物**：小伟、绣儿
- **关键动作**：小伟操作电脑、绣儿布置拍摄设备
- **关键台词**："AI只做呈现，灵魂在您手上" / "我拍的不是流量，是它的命"
- **情绪**：准备、期待
- **叙事功能**：重建开始

#### 场10 - 内景·绣架前
- **时间**：清晨
- **人物**：林素琴
- **关键动作**：看木牌、看福袋、看儿女、坐下、闭眼、落针
- **关键时刻**：这一针——稳
- **情绪**：平静、坚定
- **叙事功能**：人物完成转变

#### 场11 - 蒙太奇
- **形式**：快速剪辑
- **内容**：视频发布 → 点赞增长 → 评论 → 年轻女孩来访
- **关键台词**："阿姨……我能学吗？"
- **叙事功能**：展现传播效果、传承延续

#### 场12 - 内景·夕阳
- **时间**：夕阳
- **光线**：暖光
- **人物**：林素琴（抱孩子）、小伟、绣儿
- **关键台词**："针会老，人会老，但只要有人接——线就不会断"
- **情绪**：温暖、和解
- **叙事功能**：主题升华

#### 场13 - 结尾
- **形式**：镜头拉远
- **视觉**：绣坊亮灯、木牌发光、人来人往
- **字幕**："她守了一辈子针，差点断了线"
- **叙事功能**：开放式结尾、希望延续

## 场景需求清单

### 主场景：老绣坊
- **空间元素**：
  - 绣架（中心位置）
  - 蜀绣木牌（墙上）
  - 红色拆牌通知
  - 针盒、丝线、绣布
  - 福袋
  - 窗户（光源）
  - 桌子、椅子
  
- **光线变化**：
  - 清晨：冷灰色调
  - 傍晚：低饱和度
  - 夜：无灯/窗外冷光
  - 深夜：暖黄灯光
  - 清晨：天光微亮
  - 夕阳：暖光

### 次场景：旧屋（闪回）
- **空间元素**：油灯、绣架、简朴家具
- **人物**：外婆、小绣儿

### 特殊场景：AIGC动画
- **技术需求**：历史影像重构、手部形态变化、数字线条
- **风格要求**：流畅过渡、情感连贯

## 场景节奏分析

### 第一集：压抑→爆发
- 场1：慢节奏，极近特写，建立压抑氛围
- 场2：节奏加快，冲突密集，情绪爆发
- 场3：极慢节奏，留白，悬念

### 第二集：柔软→崩溃
- 场4-6：中慢节奏，情感铺垫
- 场7：流动节奏，视觉叙事
- 场8：节奏变化，从平静到崩溃

### 第三集：重建→希望
- 场9-10：稳定节奏，重建信心
- 场11：快节奏蒙太奇
- 场12-13：慢节奏，温暖收尾
