# 声音设计规则

## 项目: 针锋·针心
**更新时间**: 2026-05-03

## 核心声音策略

### 声音情感弧线
**克制静默 (场1-3) → 柔软对话 (场4-6) → 无声视觉 (场7) → 崩溃释放 (场8) → 温暖重建 (场9-13)**

## 决策规则

### 1. 音乐使用

**WHEN** 场1刺绣、场3孤独  
**DO** 无音乐，只有环境音和细微摩擦声  
**BECAUSE** 压抑氛围需要声音留白，让观众感受窒息感

**WHEN** 场7 AIGC动画  
**DO** 无对白，环境音乐渐入，历史感配乐  
**BECAUSE** 让视觉说话，音乐辅助时间流动感

**WHEN** 场8崩溃  
**DO** 针散开的"叮"声作为情感触发，其他声音逐渐消失  
**BECAUSE** 声音真空强化情感冲击

**WHEN** 场10-13温暖段落  
**DO** 温暖轻柔的背景音乐，不抢戏  
**BECAUSE** 情感释放需要音乐支撑，但保持克制

### 2. 环境音设计

**WHEN** 场1清晨  
**DO** 丝线摩擦声、针刺入布的细微声、远处拆迁机械闷响  
**BECAUSE** 细节音效建立真实感，远处闷响建立危机感

**WHEN** 场2冲突  
**DO** 孩子哭声后，所有声音变远（情感真空）  
**BECAUSE** 声音设计配合林素琴内心震荡

**WHEN** 场5闪回  
**DO** 油灯噼啪声、外婆温柔的声音  
**BECAUSE** 温暖回忆需要柔软的声音质感

### 3. 声音桥接

**WHEN** 场3到场4过渡  
**DO** 夜晚环境音延续到深夜，脚步声作为桥接  
**BECAUSE** 声音桥接保持时间连续性

**WHEN** 场5闪回到场6现实  
**DO** 外婆声音渐弱，现实环境音渐入  
**BECAUSE** 声音层次标记时空转换

### 4. 细节音效

**WHEN** 蜀绣工艺展现  
**DO** 针刺入布、丝线拉动、绣架摩擦的真实音效  
**BECAUSE** 声音细节增强工艺真实感

**WHEN** 场8针盒掉落  
**DO** 针散开的"叮叮"声，清晰、锐利  
**BECAUSE** 声音作为情感崩溃的触发点

**WHEN** 场10重新落针  
**DO** 针刺入布的声音，清晰、稳定  
**BECAUSE** 声音对比场1的失手，标记重建完成

## 反模式

**DON'T** 在克制段落使用煽情音乐  
**DON'T** 在对话场景过度使用背景音乐  
**DON'T** 忽略环境音的情感功能
