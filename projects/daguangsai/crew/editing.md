# 剪辑部门规则

## 项目: 针锋·针心
**更新时间**: 2026-05-03

## 核心剪辑策略

### 节奏设计
**克制缓慢 (场1-3) → 柔软过渡 (场4-6) → 流动历史 (场7) → 情感爆发 (场8) → 稳定重建 (场9-13)**

## 决策规则

### 1. 镜头时长

**WHEN** 场1刺绣、场10重新落针  
**DO** 长镜头，不打断动作连贯性，单镜头≥30秒  
**BECAUSE** 让观众沉浸在真实时间流逝中（侯孝贤原则）

**WHEN** 场2冲突升级  
**DO** 镜头时长逐渐缩短，从30秒→15秒→5秒  
**BECAUSE** 剪辑节奏配合情绪升级

**WHEN** 场8崩溃  
**DO** 长镜头捕捉完整情感过程，不切碎  
**BECAUSE** 情感爆发需要完整时间让观众共情

### 2. 切点选择

**WHEN** 场1到场2过渡  
**DO** 在动作完成后切，不在动作中间切  
**BECAUSE** 尊重动作完整性，保持克制美学

**WHEN** 场5闪回到场6现实  
**DO** 在外婆台词结束后切，声音桥接  
**BECAUSE** 情感连续性优先于视觉连续性

**WHEN** 场7 AIGC动画内部  
**DO** 在历史节点切换，保持流畅过渡  
**BECAUSE** 历史流动感需要无缝衔接

### 3. 连续性管理

**WHEN** 场1、场8、场10手部特写  
**DO** 确保针法动作连续性，手的位置、针的角度一致  
**BECAUSE** 工艺真实性依赖动作连续性

**WHEN** 场2冲突到场3孤独  
**DO** 保持空间连续性，绣坊内部布局一致  
**BECAUSE** 同一空间的不同时间段需要空间记忆

**WHEN** 场4-8连续夜晚场景  
**DO** 光线、服装、道具位置保持一致  
**BECAUSE** 时间连续性是情感累积的基础

### 4. 情感节奏

**WHEN** 第一集结尾（场3）  
**DO** 留白，不给答案，镜头停在林素琴手停住的瞬间  
**BECAUSE** 悬念驱动观众期待下一集

**WHEN** 场8崩溃后到场9准备  
**DO** 时间跳跃，不展现中间过程  
**BECAUSE** 情感最低点后需要时间跳跃重建希望

**WHEN** 场11视频传播  
**DO** 快速剪辑，展现传播速度和影响力  
**BECAUSE** 节奏加快标记故事进入积极阶段

## 反模式

**DON'T** 在克制段落使用快速剪辑  
**DON'T** 在情感爆发时切碎镜头  
**DON'T** 为了节奏牺牲动作完整性
