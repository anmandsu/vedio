## 核心创作原则

### 1. 克制美学
- 90%克制 + 10%爆发 = 最大情感冲击
- 长镜头观察 > 主观特写
- 情感留白 > 情绪宣泄
- 身体语言 > 台词说明

### 2. 真实性优先
- 真实蜀绣工艺（1/16丝，晕针/切针/滚针）
- 真实手部动作，不用替身
- 真实空间布局（文殊坊参考）
- 真实材质质感（丝线、木质、青瓦）

### 3. 色彩情感弧线
```
冷灰 (场1-6) → 过渡 (场7) → 温暖 (场8-13)
压抑/疏离    →  转折  →  希望/和解
```

## 关键场景策略

### 场1 - 第一次失手
- **导演**: 长镜头观察，不打断
- **摄影**: 极近特写针刺入绣布，自然光影
- **声音**: 无音乐，细微摩擦声 + 远处闷响
- **剪辑**: 单镜头≥30秒

### 场7 - AIGC动画（最高质量要求）
- **导演**: 历史流动感，无对白让视觉说话
- **摄影**: 横向移镜，类似长卷展开
- **声音**: 无对白，历史感配乐
- **剪辑**: 历史节点流畅过渡
- **特别注意**: 创新视觉设计，风格统一，情感连贯

### 场8 - 崩溃（情绪最低点）
- **导演**: 身体失控→情感崩溃，层层递进
- **摄影**: 长镜头捕捉完整过程
- **声音**: 针散开"叮"声触发，声音真空
- **剪辑**: 不切碎，完整情感过程

### 场10 - 重新落针（转折点）
- **导演**: 闭眼深呼吸，落针，"这一针——稳"
- **摄影**: 固定机位，手部特写
- **声音**: 针刺入布的声音，清晰稳定
- **剪辑**: 长镜头，动作完整性
