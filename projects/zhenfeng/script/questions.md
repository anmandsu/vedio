# Questions

这些问题在进入研究阶段前需要明确。部分可在后续管线中解决，部分需要用户确认。

## 需要用户确认

1. **视觉风格基准** — 是追求完全的摄影写实（如35mm胶片质感），还是允许图像带有一定插画/概念艺术质感？文学剧本倾向于高度写实（极近特写、光线细致、物理质感），但AI生成写实场景时对蜀绣细节的还原度是挑战。

2. **AIGC动画段(场7)的风格方向** — 场7的"AIGC动画"是做成中国传统水墨流动风格？针线刺绣动画风格（针线本身的运动构成画面）？还是现代数字艺术（粒子流动、数据可视化感）？不同方向对整个片的视觉调性影响很大。

3. **人物造型风格** — 是追求"像纪录片的真实人物"（普通中老年女性、非偶像化面容），还是"电影感人物"（有性格特征但仍有银幕质感）？林素琴的表演核心是"克制"，真实感面容比美化面容更有力量。

4. **最终交付形式** — 是静态故事板（每场1-3张关键帧）还是全动态视频？目前管线做静态图像 prompt → 生成静态帧是可行的，但要进入视频生成需要先锁定人物造型。

## 可在后续管线中解决

5. 蜀绣绣坊的准确空间参考 — 需要通过OpenCLI/web research找到真实的蜀绣绣坊内部照片
6. 蜀绣针法、绣架、工具的准确参考资料 — 需要专业参考图
7. 成都老街的视觉参考 — 宽窄巷子、锦里等地的建筑质感
8. 56岁女性的面部细节参考 — 需要素人肖像参考而非广告模特
9. 福袋的准确造型 — 四川地区传统福袋/香囊样式

## 脚本层面的开放问题

10. 场7的"AIGC动画"具体用什么技术实现？文学剧本中描述为流动的历史画面，但生成时是用图生视频？还是一系列静态画面剪辑？建议先用静态关键帧覆盖场7的每个历史节点（商周骨针→汉锦→唐绣→宋写意→明清绣坊→外婆→林素琴→小伟数字→绣儿发布），后续再考虑动态化。
