# Story Brief

## Logline

成都老街，一间即将被拆除的蜀绣绣坊里，固守传统的匠人母亲与拥抱科技的子女激烈碰撞。一针之偏，三代之裂——当技艺面临失传，守住手艺的形式还是让手艺活下去，成为一个家庭必须回答的问题。

## Genre And Format

- **类型**: 现实主义家庭伦理微短剧 + 非遗文化传承
- **格式**: 3 集 × 约 10-13 场，每集结构完整（起/爆/收）
- **时长**: 每集约 3-5 分钟
- **风格基准**: 克制、安静的视觉叙事，让针线和人物的细微动作承载情绪。不煽情，用细节说话。

## Core Promise

观众将看到一个手艺人家族在"被看见"和"被传承"之间的真实挣扎。这不是传统 vs 科技的二元对立，而是一个关于"什么才是真正的传承"的追问。技术不是敌人，封闭才是。

## Audience Emotion

- 第一集：压抑 → 震惊（那一巴掌）
- 第二集：心疼 → 释然（福袋真相 + AI影像）
- 第三集：希望 → 温暖（新徒到来，线未断）

观众最终应该感到：传统并不拒绝变化，传承可以有新的形式。被看见本身就是一种活下去的方式。

## World Rules

1. **绣坊是封闭宇宙** — 外面的拆迁声、手机屏幕、AIGC影像都是"入侵者"。空间的打开对应着人物内心的打开。
2. **针是灵魂载体** — 针的"稳"与"歪"直接对应林素琴的精神状态。穿针、失手、落针、断线，都是人物弧光的物理化。
3. **福袋是传承的信物** — 外婆不直接出场，但福袋承载着"真正的传承精神"。它不是"守住"，而是"传下去"。
4. **科技不是魔法** — AIGC影像不是炫技，而是"用技术还原记忆"。它的功能是情感触发，不是技术展示。
5. **耳垂的小洞是林素琴的私人密码** — 多次出现的手势（摸耳垂），是她与自己内心对话的身体语言。

## Main Conflict

**表层冲突**: 绣坊即将被拆除（外部压力：拆迁倒计时）
**中层冲突**: 母亲 vs 子女（内部压力：传统方式 vs 现代方式）
**深层冲突**: 林素琴 vs 自己（"守了一辈子，守错了？"——传承的本质是什么？）

## What Must Not Be Lost

1. **针的物理性** — 针穿过布料的声音、丝线的摩擦感、手的颤抖。这些微观感受是故事的"呼吸"。
2. **情绪的低回而非高亢** — 最高潮处是林素琴蹲在地上捡不起针，不是那巴掌。崩溃是安静的。
3. **外婆的精神锚点** — "别死守，要传下去"是整部片的价值观核心，必须贯穿始终。
4. **开放式结尾** — 不是"大团圆"，而是"新的开始"。小女孩问"我能学吗"，林素琴点头，针线继续——但不需要展示结果。
5. **蜀绣的视觉真实性** — 针法、绣布、丝线质感、绣架结构必须经得起推敲。非遗不是布景，是主角。
