# Department Rules: 《针锋·针心》

> 每一条规则都可被导演/摄影/美术Agent直接执行。格式: When → Do → Because。

---

## Director Rules (是枝裕和工艺锚定)

### Rule D1: 静态凝视 — 摄影机不表演
**When** 人物处于独处状态（绣、坐、看木牌）
**Do** 锁定三脚架，机位在人物眼平高度，不推不拉不摇不移。让人物的微动作（手颤、呼吸、摸耳垂）承载画面重量。
**Because** 摄影机的静止迫使观众"在场"。是枝裕和: "摄影机不应该比人物更早知道情绪。"
**Anti-pattern**: 用 push-in 强调情绪 → 静止本身就是强调。

### Rule D2: 沉默是第三个人物
**When** 情绪高点（巴掌后、福袋递出后、针散落后、崩溃时刻）
**Do** 延长停顿至3-5秒。不填音乐。让环境声（针落声、窗外风、呼吸）说话。
**Because** 观众需要时间"进入"情感。台词释放情绪，沉默承载情绪。
**Anti-pattern**: 用配乐推动情绪 → 环境声才是本片的配乐。

### Rule D3: 物件承载情感，不是台词
**When** 需要传达人物的内心状态
**Do** 拍她手中的东西（颤抖的针、散落的针、福袋、木牌），不拍她的脸解释情绪。
**Because** 林素琴的人物设定就是"不善表达"。让她用台词说"我很难过"是对人物的背叛。
**Anti-pattern**: 面部特写 + 眼泪 → "捡不起针"比任何表情都有力。

### Rule D4: 冲突不靠对白音量升级
**When** 场2三人争执
**Do** 对白越重要，声音越轻。巴掌是物理爆发，但前后的对白是"收"的——林素琴说"别碰这块牌"时声音极低。
**Because** 是枝裕和: "最伤人的话往往是轻声说的。"真实家庭冲突不是话剧。
**Anti-pattern**: 让任何人喊叫 → 全场只有绣儿爆发一次（指向木牌那句），其余都是克制的。

### Rule D5: 日常动作即仪式
**When** 展示蜀绣工艺
**Do** 把穿针、劈丝、落针这些动作拍成微仪式——不加快，不用蒙太奇，不给教程感。就是一个人在做她做了几十年的事。
**Because** 蜀绣的"魂"不在于讲它的伟大，在于展示做它的人的样子。
**Anti-pattern**: 用快速剪辑展示"炫技" → 蜀绣不是表演，是呼吸。

### Rule D6: 结尾不闭合
**When** 场11-13，故事收束
**Do** 小女孩问"我能学吗"，林素琴点头——不展示教学过程，不展示成果。镜头拉远，绣坊亮灯，人来人往。结束。
**Because** 传承不是一个结果，是一个开始。观众自己完成故事。
**Anti-pattern**: 大团圆合照、字幕总结、全员微笑。

## Cinematography Rules

### Rule C1: 固定机位主导
**When** 场1/2/3/4/6/8/10/12
**Do** 三脚架锁定。全场唯一允许的运动是场13的极缓慢dolly back（告别）和场7的AIGC流动画面。
**Because** 是枝裕和的镜头语言核心: 让内容运动，不让摄影机运动。
**Anti-pattern**: 手持晃动制造紧张 → 本片的紧张来自"人被困在空间里"。

### Rule C2: 光线即时间，时间即情绪
**When** 每个场景的光线设定
**Do** 
- 场1: 左窗冷灰晨光(~5500K) — 孤独日常
- 场2: 右窗夕阳光(~3200K) — 温暖正在消失
- 场3: 窗外街灯冷蓝(~6000K) — 孤绝
- 场4: 台灯暖黄(~2800K) — 私密脆弱
- 场5: 油灯极暖(~2000K) — 记忆金色
- 场8: 暖灯+屏幕冷蓝混合 — 内心撕裂
- 场10: 天光微亮(~4500K) — 新生
**Because** 林素琴的故事发生在一个房间里，光线的变化就是时间的流逝，就是情绪的变化。
**Anti-pattern**: 所有场景统一调色 → 光线必须随叙事演进。

### Rule C3: 针的视点
**When** 场1/场8/场10 穿针、失手、落针
**Do** 极近特写 (微距)。针尖入布、丝线拉紧、手部微颤——这些都是故事的"呼吸"。手指皮肤纹理可见，指甲干净但无修饰。
**Because** 这个故事的"动作戏"就是针和手的关系。特写针就是特写灵魂。
**Anti-pattern**: AI生成常见的手部错误（六指、诡异姿势）→ 必须用视觉指纹严格锁定。

### Rule C4: 绣坊空间镜头
**When** 每次切回绣坊空镜或人物独处
**Do** 35mm镜头，稍广但不畸变。空间包含三个层次: 前景(绣架/人物) → 中景(木牌/工具) → 背景(窗外/后门)。空间深度要真实可感。
**Because** 绣坊是第三个主角。它的空间关系(门在哪、窗在哪、木牌在哪个位置)必须在每个镜头中保持一致。
**Anti-pattern**: 随意改机位导致空间连续性混乱。

### Rule C5: AIGC动画段(场7)的视觉语言
**When** 场7《蜀绣千年》影像
**Do** 这是唯一"摄影机可以自由"的段落。但自由的逻辑是: 画面内部流动（针线生长、历史纹样演变）主导，不是摄影机运动主导。色调从远古(暖土色) → 盛世(金红) → 数字(冷蓝) → 补全(暖金)。结尾停在外婆未完成的绣样 → AI补全后的完整绣样。
**Because** 场7不是"炫技"，是一封家书。它的情感功能是让林素琴"看见"传承的另一条路。
**Anti-pattern**: 做成科幻特效大片 → 它应该是安静的、流动的、像一滴墨在水里散开。

## Production Design Rules

### Rule PD1: 绣坊是"住过的"，不是"设计过的"
**When** 构建绣坊视觉
**Do** 所有木器有使用痕迹（手磨光的边角、深浅不一的木色）。工具不是摆件。墙上有反复修补痕迹。丝线不是整齐排列的装饰——是正在用的工作材料。
**Because** 这个空间承载了三代人的时间。"被住了几十年"才是它的视觉身份。
**Anti-pattern**: 整洁展厅风 → AI容易生成"漂亮但没人用过"的空间，必须用prompt压回去。

### Rule PD2: 蜀绣绣品的视觉准确性
**When** 画面包含绣品/正在绣的作品
**Do** 绣品图案以花鸟、山水、凤凰等传统题材为主。针法痕迹可见（不同针法呈现不同纹理）。正在绣的作品应能看到针还在布上的状态——不完整的美。
**Because** 如果绣品看起来像印刷品或机器刺绣，整个"非遗传承"的主题就站不住。
**Anti-pattern**: 模糊的"看起来像刺绣"的纹理 → 必须有针法痕迹。参考Bilibili针法实录视频。

### Rule PD3: 色彩系统
**When** 全片调色/角色配色/场景配色
**Do**
- 绣坊主调: 木褐(#6B3A2E) + 墙灰白(#E8E0D5) + 丝线红(#C41E3A)
- 林素琴: 深色系（藏青/深灰），不穿任何"非遗表演服"
- 绣儿: 现代便装，比母亲亮一度但不鲜艳
- 小伟: 中性色（灰/蓝），不抢眼
- 光线的冷暖变化主导"氛围调色"，不在后期加滤镜
**Because** 色彩来自材质和光线，不是来自调色软件。是枝裕和的色彩是"住出来的"。
**Anti-pattern**: 给林素琴穿旗袍/刺绣外套 → 她不是"非遗代言人"，她是一个匠人。

### Rule PD4: 关键道具锚点
**When** 福袋、木牌、针盒在画面中出现
**Do**
- 福袋: 手掌大，暗红绸缎，边缘磨损。每次出现保持同一外观。
- 木牌"蜀绣": 约60×40cm，深木色，居中悬挂。是空间锚点。
- 针盒: 老木盒，内有分隔。场8打翻后针散落一地——这是全片最重要的道具镜头。
- 耳垂小洞: 林素琴摸耳垂是她的私人密码——场1/场2/场8各一次，角度一致。
**Because** 连续性不是"后期检查"，是"前期锁定"。每个重复道具必须建立视觉指纹。
**Anti-pattern**: 不同镜头中道具外观不一致 → visual bible必须锁定。
