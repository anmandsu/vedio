# Scene: 老绣坊 (The Old Embroidery Workshop)

## Narrative Function
全片核心空间。13场戏中至少10场发生在这。它不仅是背景——它是第三个主角。光线变化、木牌状态、针的稳/歪——都是叙事。

## Spatial Map

**空间: 约30-40㎡长方形，成都老街底商改建的前店后坊格局。**

```
       北(后门→里屋/厨房)
       ↑
  ┌─────────────────────┐
  │  丝线架(整面墙)     │  ← 数百线筒按色系排列
  │  旧木柜(福袋在此)   │
  │                     │
  │  后门(半开→里屋)    │
  ├─────────────────────┤
窗│                     │窗
←│  绣架(中央偏左)     │→  (右窗=场2夕阳光源)
左│  ←1.5m宽柏木绣架   │
  │  绣架旁小边桌      │
  │  (针/剪刀/瓷碟)    │
  ├─────────────────────┤
  │  备用绣架(角落)     │

```

## Color And Materials

**主调: 木褐 + 墙白 + 丝线艳**

| 元素 | 材料 | 颜色 | 质感 |
|------|------|------|------|
| 地面 | 老青砖/水泥地 | 深灰,有磨损区 | 粗糙、有年代的凹痕 |
| 墙体 | 老砖墙+白灰 | 暖白微黄(#E8E0D5) | 斑驳、修补痕迹 |
| 梁柱 | 老杉木 | 深褐(#6B3A2E) | 木纹深、有裂纹 |
| 门窗 | 老木框+玻璃 | 暗红褐 | 油漆剥落、合页生锈 |
| 绣架 | 老柏木 | 深红褐,扶手区磨光 | 光滑与粗糙并存 |
| 丝线架 | 老木 | 同梁柱色 | 线筒色彩最艳 |
| 竹椅 | 老竹 | 蜜色(年久变色) | 光滑、坐面微凹 |

**绝对不允许**: 日式障子/榻榻米/暖帘/枯山水/灯笼。地板不是榻榻米，是老青砖或水泥地。窗户不是日式格子障子，是中式木框玻璃窗。

## Recurring Props
- 木牌 "蜀绣" (后墙正中，对门悬挂)
- 绣架 (中央偏左，面朝左窗)
- 丝线架 (北墙整面)
- 福袋 (北墙旧木柜上——"顺手放那儿")
- 针盒 (绣架旁小边桌)
- 老茶桌+两把竹椅 (入口区)
- 红线拆牌通知 (入口区墙上，场2)
- 外婆旧照片 (可能在小伟电脑上/墙上)

## Camera-Friendly Anchors
- 绣架主体 + 左窗自然光 = 最天然的拍摄轴
- 丝线架 = 最天然的"色彩背景"，清晨阳光穿透时在墙上投射线影
- 木牌 = 空间的"道德中心"，正对门口。多个角度可拍
- 北墙后门半开 → 可见但不可达的空间深度("画框中的画框")
- 绣架侧面的丝线/绣布可作前景遮挡构图

## Sound Bed
- 针穿过绣布: "沙"——细微摩擦声
- 丝线拉紧: "呲"——光滑纤维摩擦
- 竹绷架调整: 轻微嘎吱
- 线轴滚动: 轻响
- 窗外: 远处拆迁声(场1-8)、老街日常声(场9-13)
- 门推开: 老木门合页轻微金属声
- 脚步声: 青砖地上的布鞋声(林素琴)、运动鞋声(绣儿/小伟)

## Anti-Patterns
- ❌ 日式空间——无榻榻米、无障子、无和式灯具
- ❌ 展厅式整洁——无全新道具、无整齐摆放的装饰
- ❌ 博物馆式灯光——无射灯、无展柜灯
- ❌ 任何"非遗博物馆"/"文化展厅"的视觉效果——这是一个工作坊，不是景点
