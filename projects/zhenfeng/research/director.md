# Director Research: 是枝裕和 (Kore-eda Hirokazu)

## Why Kore-eda for 《针锋·针心》

这个剧本的核心不是"传统 vs 科技"的辩论，而是**一个家庭内部的情感断裂与修复**。林素琴不是反派，绣儿不是叛逆者，小伟不是救世主——他们是一个家庭里彼此伤害又彼此深爱的一家人。这恰好是是枝裕和拍了三十年的主题。

是枝裕和的方法论最适合本片的三个原因：
1. **他拍的是"不表达的人"** — 林素琴克制、内敛、不善表达，正是是枝裕和最擅长处理的人物类型
2. **他用空间和物品承载情感** — 绣坊、针、福袋、木牌——这些物件是情感的载体，不需要角色说出来
3. **他相信沉默比台词更有力量** — 本片最重的一场戏（场8崩溃）不是喊出来的，是蹲在地上捡不起针

## Kore-eda's Craft Rules → Applied to 《针锋·针心》

### Rule 1: 静态观察 — 摄影机不"表演"

**是枝裕和的做法**: 锁定镜头，低机位（榻榻米视线高度），摄影机只在必要时缓缓跟随人物。摄影机本身不做"情绪表达"——推拉摇移留给人物自己的身体语言。

**应用于本片**:
- 绣架前林素琴的镜头：机位固定在她坐姿的眼平高度。针的运动是画面里唯一的活动。
- 场2冲突戏：摄影机不跟吵架的人移动。它停在原地，让人物走进画面/走出画面。巴掌那一下，摄影机不动——观众被迫"在场"。
- 场8崩溃：镜头固定在中景，林素琴蹲下捡针时身体出画，只看到她的背和手。摄影机不俯拍，不"同情"。它在同一个高度，像一个沉默的家庭成员。
- **绝对禁止**: 冲突戏用晃动镜头制造紧张感。是枝裕和的紧张感来自"发生了什么"，不是"摄影机晃了"。

### Rule 2: 负空间 (Ma) — 沉默是第三个人物

**是枝裕和的做法**: 对白之间的沉默不是空白，是情感发生的空间。人物说完话后的那几秒，比说的话本身更重要。

**应用于本片**:
- 场1: 针歪了之后。林素琴看着针。5秒。只有远处拆迁声。没有内心独白。
- 场2: 巴掌之后。孩子哭声渐远。林素琴手在颤。3秒。然后她低声说"滚"。不是喊的。
- 场4: 绣儿递出福袋。林素琴没接。这里的沉默至少4秒。观众需要时间理解"她为什么不接"。
- 场8: 小伟说"我用AI把它补完了"。之后至少3秒。林素琴的反应不是在台词里，是在呼吸里。
- **绝对禁止**: 在情绪高点填音乐。是枝裕和几乎从不在关键情感时刻用配乐。环境声（窗外风声、针落地的声音）就是音乐。

### Rule 3: 日常空间作为情感容器

**是枝裕和的做法**: 空间不是布景，是人物内心世界的外化。杂乱、磨损、使用痕迹——这些不是美术细节，是时间的证据。

**应用于本片**:
- 绣坊必须看起来"被住了几十年"。绣架的木纹被手磨光了。墙上有反复修补的痕迹。工具不是摆件，每件都有使用痕迹。
- 光线即叙事: 场1(冷灰晨光) → 场2(傍晚斜阳) → 场3(窗外冷光) → 场4(暖黄灯光) → 场10(天光微亮)
- 木牌"蜀绣"不是装饰——它是林素琴每一次抬头看到的权威象征。它的位置必须在多个镜头中保持一致，因为它是空间的"道德中心"。
- **绝对禁止**: 整洁得像展厅的绣坊。是枝裕和的家是"住过的"，不是"设计过的"。

### Rule 4: 微观动作 > 宏大表情

**是枝裕和的做法**: 他不让演员"演情绪"，他让演员"做动作"。一个剥橘子皮的孩子比一个嚎啕大哭的孩子更动人。情绪在动作里，不在脸上。

**应用于本片**:
- 林素琴摸耳垂 —— 这是她的"私人密码"，全片出现3次。不需要解释为什么，观众会自己理解。
- 场8: 林素琴蹲下捡针。手在抖。怎么都捡不起来。这个动作就是整部片的情感顶点。不需要哭喊，不需要独白。就是捡不起一根针。
- 场10: 重新落针。针稳了。不需要微笑，不需要"松了一口气"的表情。稳了就是稳了。
- 绣儿: 场4递福袋时，手不是果断伸出去，是犹疑的。手指在福袋边缘摩挲了一下才松手。
- **绝对禁止**: 特写泪流满面的脸。是枝裕和从不这样拍。

### Rule 5: 结尾不闭合 — 留一条缝

**是枝裕和的做法**: 电影结束时不是"问题解决了"，而是"生活在继续"。镜头拉远，人物回到日常。观众带着余韵离开，不是带着答案。

**应用于本片**:
- 场13结尾: 镜头从绣坊拉远。灯亮着。人来人往。不需要字幕说"蜀绣得救了"。灯亮着就够了。
- 小女孩"我能学吗"之后——不展示她学的过程。林素琴点头。切黑。观众自己完成这个故事。
- **绝对禁止**: 大团圆合照。全员微笑。字幕"从此蜀绣再次繁荣"。

## 是枝裕和的反模式（本片绝对不能做的事）

| 不要 | 为什么 |
|------|--------|
| 用配乐推动情绪 | 环境声（针声、风声、脚步声）才是真正的配乐 |
| 特写泪脸 | 捡不起针比嚎啕大哭有力一百倍 |
| 晃动镜头制造紧张 | 本片的紧张来自"人被困在空间里"，不是"摄影机在动" |
| 让任何人说出"我错了" | 是枝裕和的人物从不用台词完成转变。动作就是转变 |
| AI影像段做成炫酷特效 | 场7的AIGC动画应该是"安静地流动"，不是"炫技"。它是一封家书，不是一场表演 |
