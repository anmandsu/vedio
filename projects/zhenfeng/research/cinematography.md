# Cinematography Research

## Visual Language Anchor: Kore-eda Naturalism × Shu Embroidery Intimacy

## Camera Philosophy

### Master Rule: Static, Observe, Don't Perform

摄影机的任务是"在场"，不是"表演"。是枝裕和的摄影机是一个沉默的家庭成员，坐在角落里，不参与对话，但什么都看到了。

### Shot Size Logic

| Scene | Shot Size | Rationale |
|-------|-----------|-----------|
| 场1 (林素琴独绣) | Extreme close (针+手) → Wide (绣坊空间) | 从微观到宏观，建立针与空间的尺度关系 |
| 场2 (三人冲突) | Medium为主，少量Wide包三人 | 摄影机不跟随吵架走位。它定在一个位置，让人物进出画面 |
| 场3 (林独坐) | Wide (空旷绣坊+一个人) | 空间的空旷 = 内心的空洞 |
| 场4 (福袋) | Medium close (手+福袋) → Medium (两人) | 物件先行，关系后置 |
| 场7 (AIGC动画) | 流动画面，无固定景别 | 这是唯一"摄影机可以自由"的段落 |
| 场8 (崩溃) | Medium，不切特写 | 摄影机保持"尊重距离"，不侵入崩溃 |
| 场10 (重新落针) | 同场1的角度和景别，但光线变了 | 呼应开场，但"稳了" |
| 场13 (结尾) | Wide，拉远 | 把绣坊交还给世界 |

### Camera Movement

- **全场1/2/3/4/8/10/12**: 完全静态。三脚架锁定。
- **场7 (AIGC)**: 唯一允许流畅运动的段落——但运动来自画面内部的流动（针线动画），不是摄影机推拉。
- **场13**: 极缓慢的dolly back。不是"炫技"，是"告别"。

### Lens Choice

- 标准焦段 (35mm-50mm) 为主。不用广角制造夸张空间感，不用长焦偷窥人物。
- 35mm: 绣坊空间镜头，稍广但不变形，让观众感觉"站在房间里"
- 50mm: 人物中景，是枝裕和最爱——和人眼最接近的焦段，不美化不丑化
- 微距: 针+手部极近特写（场1/8/10），需要极高细节

### Lighting Reference

光线不是照明工具，是叙事语言：

| Scene | Light Source | Color Temp | Atmosphere |
|-------|-------------|------------|------------|
| 场1 | 左侧大窗自然光 | 冷灰 (~5500K) | 清冷、孤独、日常 |
| 场2 | 右侧窗夕阳光 | 暖金 (~3200K) + 冷灰混合 | 冲突发生在"温暖正在消失"的光线中 |
| 场3 | 窗外街灯冷光 | 冷蓝 (~6000K) | 孤绝 |
| 场4 | 暖黄台灯 | 极暖 (~2800K) | 私密、脆弱、真诚 |
| 场5 | 油灯 | 极暖 (~2000K) | 记忆的金色 |
| 场8 | 暖黄+屏幕冷光混合 | 冷暖冲突 | 内心撕裂的视觉化 |
| 场10 | 天光微亮 | 中性偏暖 (~4500K) | 新生 |
| 场12 | 夕阳暖光 | 暖金 (~3200K) | 和解 |
| 场13 | 绣坊内暖灯 | 暖 (~3000K) | 余韵 |

### Screen Direction

- 林素琴大多数时间面向画面左侧（过去/传统方向）
- 绣儿和小伟从画面右侧进入（未来/变化方向）
- 场10: 林素琴重新落针时，脸转向右侧——第一次面向未来
- 场12: 三人面对同一方向（右侧窗外夕阳）——第一次方向统一

### Anti-Patterns (镜头绝对不做的)

| 不要 | 原因 |
|------|------|
| 手持晃动 | 不是纪录片，是"在场的观察者" |
| 快速变焦/推拉 | 观众的注意力应该由内容引导，不是由镜头"命令" |
| 无人机航拍绣坊 | 故事的尺度是"一间屋子里的一个家庭"，不是"一座城市的宏大叙事" |
| 滤镜/风格化调色 | 光线来自窗户和灯泡，不是来自调色软件 |
| 慢动作 | 生活的节奏不需要特效 |
