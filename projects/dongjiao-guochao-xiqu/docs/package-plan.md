# 东郊记忆国潮戏曲造型体验馆套餐策划案

## 1. 项目定位

**定位语：工业遗址里的国潮戏曲造型实验室。**

体验馆不做普通汉服租赁，也不做严格复原戏曲行头馆，而是把戏曲凤冠、帅盔、水袖、靠旗、珠穗、翎子等符号，与东郊记忆的工业遗存、音乐演艺、文创消费和年轻人打卡属性结合，形成“国潮戏曲妆造 + 影像打卡 + 文化体验”的复合消费空间。

核心差异化：

- **一眼识别**：凤冠与帅盔作为超级符号，解决普通汉服馆辨识度弱的问题。
- **场地反差**：传统戏曲头面进入工业砖墙、钢梁、管线和霓虹空间，形成传播记忆点。
- **内容友好**：适合小红书图文、抖音变装、情侣短片、研学团建。
- **成都限定**：加入芙蓉花、竹影、川剧脸谱色块、东郊工业纹样。

目标客群：

- 18-35岁女性游客、本地年轻人、闺蜜出行、生日写真。
- 情侣、婚前创意照、纪念日用户。
- 亲子研学、学校社团、企业团建。
- 来东郊记忆看演出、逛市集、喝咖啡的即时消费人群。

## 3. 套餐细化

### A. 凤冠一刻

目的：低门槛吸引东郊记忆即时客流，快速形成门店热闹感。

执行要点：

- 只开放轻量头饰和半身搭配，控制单客时间。
- 重点设置镜前短视频灯位，适合“上头一秒变装”。
- 结账时引导升级标准套餐，抵扣部分快闪费用。

推荐话术：

> 逛东郊记忆，给自己戴一次凤冠或帅盔。半小时出片，不耽误下一站。

### B. 梨园新妆

目的：承担月销量主力，形成稳定客单。

执行要点：

- 妆面保留戏曲眼妆、眉形、唇形灵感，但适合日常审美。
- 服装以轻量改良为主，方便顾客行动。
- 三个室内场景固定为红金戏台、黑金武场、工业霓虹。

推荐话术：

> 不是汉服写真，是一次真正带戏曲符号的国潮造型体验。

### C. 凤冠霞影 / 少年将军

目的：负责品牌大片、账号内容、达人合作和高客单利润。

执行要点：

- 凤冠款突出珠穗、凤凰、红金层次、肩部披帛。
- 帅盔款突出盔体轮廓、红缨、甲片、腰封、披风。
- 外景选择东郊记忆砖墙、钢梁、管线、演艺门头或夜景灯牌。

推荐话术：

> 把戏曲里的凤冠和帅盔，拍进东郊记忆的工业街巷。

### D. 凤冠与帅盔

目的：建立差异化爆款，形成情侣、闺蜜、纪念日传播素材。

三套主题：

- **将军与公主**：一红金凤冠，一黑金帅盔；情绪是守护与并肩。
- **女将与少帅**：一女将帅盔，一银甲少帅；情绪是英气、锋利、对望。
- **双生武旦**：两套轻甲戏曲造型；情绪是镜像、默契、动作感。

执行要点：

- 必须安排一个双人对望镜头、一个并肩全身镜头、一个局部头饰特写。
- 短视频以“素人进门 -> 戴冠/戴盔 -> 转身外景”为结构。

### E. 一日入梨园

目的：填充工作日客流，建立文化背书。

执行要点：

- 将“讲解”控制在15-20分钟，避免像课堂。
- 每人至少有一次试戴、一次身段动作、一次合影。
- 面向学校时强化非遗和戏曲审美，面向企业时强化团队仪式感。

## 4. 价格与利润结构

默认门店面积：80-150平方米。

价格梯度：

- 引流款：99-199元，靠高频转化和现场升级。
- 主力款：399-699元，承担主要营收。
- 利润款：999-1599元，承担品牌传播和毛利。
- 双人款：1699-2699元，形成差异化和节日峰值。
- 团体款：128-298元/人，填补平日档期。

加购项：

- 加精修：30-80元/张。
- 加短视频：199-499元/条。
- 加外景：199-399元/人。
- 拍立得：20-39元/张。
- 头饰周边、流苏耳饰、香囊、贴纸：19-199元。

## 5. 上线节奏

### 试运营前2周

- 完成8套核心样衣：4套凤冠线、4套帅盔线。
- 完成4个室内拍摄场景。
- 产出12组样片，覆盖单人、双人、团体。
- 邀约10-20位本地达人/素人试拍，换取内容反馈。

### 试运营第1个月

- 主推 `凤冠一刻` 和 `梨园新妆`，快速验证客流与转化。
- 每周至少发3条小红书图文、5条抖音短视频。
- 记录咨询来源、套餐转化率、单客时长、加购率、返修率。

### 稳定运营第2-3个月

- 推出 `凤冠与帅盔` 双人爆款。
- 每月一个限定主题：女将月、凤冠生日季、毕业国潮照、七夕双人帅盔凤冠。
- 与园区咖啡、剧场、音乐活动、国潮市集做联名套票。

## 6. 验收指标

- 快闪套餐现场咨询转化率达到25%以上。
- 标准套餐成为月销量主力。
- 双人套餐能稳定贡献小红书/抖音传播素材。
- 每套造型一眼能识别出凤冠或帅盔，而不是普通汉服写真。
- 用户从入店到出片流程不卡顿，标准套餐控制在120分钟内。
