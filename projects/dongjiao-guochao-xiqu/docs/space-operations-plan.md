# 空间与运营方案

## 1. 空间定位

体验馆空间需要像“戏曲后台 + 国潮摄影棚 + 工业遗址展厅”的混合体。顾客一进门先看到凤冠和帅盔，而不是普通服装架。

整体气质：

- 戏曲符号：凤冠、帅盔、翎子、水袖、靠旗、珠穗。
- 工业场域：裸砖、金属梁、管线、铆钉、旧厂房色彩。
- 国潮表达：红金、黑金、银白、霓虹、电光蓝少量点缀。
- 成都限定：芙蓉花、竹影、川剧脸谱色块、东郊记忆工业纹样。

## 2. 五区布局

### 前厅：凤冠帅盔陈列墙

功能：第一眼记忆点、等候区、咨询成交区。

配置：

- 中央陈列一顶红金大凤冠和一顶黑金帅盔。
- 背景使用深炭黑金属板，嵌入细红色灯线。
- 墙面不要大段介绍文字，保留“可拍照”的视觉干净度。

### 妆造区：6-8个妆位

功能：完成妆面、头饰、花絮拍摄。

配置：

- 暖白镜前灯，色温约4000K，避免过冷显脏。
- 台面留出头饰、流苏、假发包、贴片收纳。
- 每个妆位设置可拍短视频的镜前灯位。

### 服装区：按产品线陈列

功能：选款、加购、风格教育。

分区：

- 凤冠线：红金、银白、黑金、川剧花旦。
- 帅盔线：红缨、黑金、银甲、女将军。
- 双人线：将军与公主、女将与少帅、双生武旦。

### 摄影区：四个固定场景

1. **红金戏台**：红幕、金边、木地台、局部水袖动线。
2. **黑金武场**：黑墙、金属甲片、长枪/令旗道具、斜向硬光。
3. **工业霓虹**：砖墙、管线、冷暖霓虹、东郊记忆式旧厂房气质。
4. **川蜀花窗**：芙蓉花窗、竹影、红白脸谱色块，适合轻妆和研学。

### 零售区：低价周边与加购

功能：提高离店客单。

品类：

- 发簪、流苏耳饰、戏曲贴纸、国潮香囊。
- 凤冠/帅盔主题拍立得相框。
- 小型头饰体验包、妆面贴纸。

## 3. 动线

标准动线：

预约/进店咨询 -> 选套餐 -> 选凤冠或帅盔风格 -> 妆面 -> 服装 -> 室内拍摄 -> 外景加购 -> 选片/加购 -> 离店分享。

快闪动线：

进店 -> 选轻量头饰 -> 半妆/贴片 -> 镜前自拍 -> 支付/升级。

团体动线：

集合讲解 -> 分组试戴 -> 身段动作 -> 分组拍摄 -> 合影 -> 周边加购。

## 4. 内容运营

### 小红书

主话题：

- 成都东郊记忆最出片国潮戏曲妆造
- 凤冠不是婚服，是我的国潮战袍
- 在工业遗址里戴一次帅盔

内容结构：

- 3图封面：素人前后对比、头饰特写、外景成片。
- 标题突出“东郊记忆、凤冠、帅盔、国潮、出片”。
- 正文少讲道理，多放套餐体验、时长、价格区间、拍摄建议。

### 抖音

视频结构：

- 3秒素人入店。
- 5秒上妆/戴冠/戴盔。
- 3秒转身定格。
- 5秒工业外景大片。
- 3秒价格锚点或预约引导。

固定镜头：

- 凤冠珠穗贴近镜头晃动。
- 帅盔红缨甩动。
- 水袖从镜头前扫过转场。
- 工业砖墙前回头。

## 5. 人员配置

最低试运营配置：

- 店长/销售 1人
- 妆造师 2人
- 摄影师 1人
- 后期/短视频兼职 1人
- 周末兼职接待 1-2人

高峰期：

- 保证一个妆造师同时只服务1-2位顾客。
- 快闪套餐单独排队，避免挤占标准套餐时段。

## 6. 风险控制

- 戏曲元素要尊重传统身份，不乱贴“京剧/川剧/汉服”标签。
- 头饰重量控制，快闪款必须轻量化。
- 外景拍摄提前确认园区管理要求。
- 价格不要只卷低价，主力利润来自标准款升级和双人款。
- 店内灯光不要过度红蓝，妆面会显脏；红蓝霓虹只放在摄影区。
