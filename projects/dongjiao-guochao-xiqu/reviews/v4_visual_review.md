# V4 Visual Review

## Summary

V4 uses the user-provided traditional opera references as the main img2img base. The set is stronger than V2/V3 for this project because it preserves:

- black forehead opera hair patches
- pink eye makeup and red lip structure
- blue-white-pink bead flowers
- red pom-poms
- pearl tassels and hanging bead strings
- large curved lingzi / pheasant-feather arcs
- xiqu sleeve and hand-gesture vocabulary
- Eastern Suburb Memory compatible red-brick / industrial studio context

## Recommended Uses

| File | Best Use | Notes |

## Issues

- V4整体偏旦角/凤冠/翎子方向，帅盔的男性武将产品线需要单独再用帅盔参考图强化。
- `v4_02` 左侧摄像机元素保留较多，适合“拍摄体验”，不适合纯造型海报。
- `v4_03` 的三人构图很适合套餐，但不是严格意义上的单人“发型设计效果图”。
