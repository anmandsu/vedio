# Style Correction: Avoid Gothic Drift

## User Feedback

The prior modern-fusion direction risks becoming too gothic and no longer reads as Chinese Guochao.

## Corrected Style Direction

Keep:

- Traditional xiqu headwear shape
- black forehead hair patches
- red pom-poms
- blue-white-pink bead flowers
- pearl tassels
- curved lingzi arcs
- water sleeves and opera gesture
- East Suburb Memory red-brick setting

Remove / avoid:

- black leather dominance
- techwear / tactical harness
- cyberpunk darkness
- gothic black-red mood
- fantasy armor
- over-dark industrial styling

Add:

- 新中式短褂 / 改良云肩 / 盘扣
- 马面裙或百褶裙结构
- 宋锦、织锦、缂丝感纹样
- 珠绣、流苏、轻纱、绣花薄纱
- 明亮国潮配色：胭脂红、湖蓝、粉白、金、玉白
- 现代但温润的时尚廓形：短外套、伞裙、直筒裤、运动鞋/短靴可少量出现
- 高级国潮摄影：明亮、华丽、清透，不压暗

## Prompt Rule

Use `Chinese contemporary Guochao elegance` instead of `street-couture`, `techwear`, `leather`, or `gothic`.
