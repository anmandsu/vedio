# Failed Patterns

## 2026-05-08 | Gothic / Cyberpunk Drift

- User said: "太哥特了，不是中国国潮风格了."
- What failed: Modern fusion prompts using street-couture, black leather, techwear, dark industrial lighting, tactical harness, and armor language pushed the result away from Chinese Guochao and toward gothic/cyberpunk/fantasy.
- Avoid next time: black leather dominance, techwear, cyberpunk darkness, tactical harnesses, fantasy armor, samurai/kimono/Japanese cues, high-contrast dark industrial mood.
- Better direction: bright breathable Guochao, red/blue/ivory/jade/pink/gold palette, brocade, embroidery, cloud collar, cloud shoulder, pankou, pearl tassels, gauze, water-sleeve panels.

## 2026-05-08 | Too Traditional / Generic New-Chinese Clothing

- User said: Pankou and cloud shoulder are okay, younger for ages 16-35, but do not use mamian skirt / generic new-Chinese style.
- What failed: If the prompt says "new Chinese" too broadly, the model tends toward long robes, mamian skirts, hanfu-adjacent silhouettes, or costume rental looks.
- Avoid next time: mamian skirt, long new-Chinese robe, generic hanfu, palace costume, bridal styling.
- Better direction: cropped or mid-length short jackets, culottes, skirt-shorts, wide-leg pants, straight trousers, cloud-collar capelets, detachable sleeves, clean boots/sneakers.

## 2026-05-08 | Body-Friendly Misread As Plus-Size Body

- User said: The covering designs made the people too fat; keep the person from becoming fat and redesign.
- What failed: Asking for "slightly chubby friendly" without separating garment fit from body type caused the image model to alter the character body.
- Avoid next time: Do not ask only for "plus-friendly" or "slightly chubby" without a body constraint.
- Better direction: State that the model remains normal-bodied/average-to-slim, while the clothing is forgiving, hip-covering, mid-length, and suitable for real slightly chubby customers.

## 2026-05-08 | Blurry Client PDF Export

- User said: The first mobile PDF looked blurry and needed a non-compressed version.
- What failed: Compressed PDF export is not enough for image-heavy design review.
- Avoid next time: Do not make only a compressed/phone-optimized PDF when the deliverable is visual design approval.
- Better direction: Keep both mobile-readable and full-resolution/high-quality PDF variants, and preserve source HTML plus image folders.
