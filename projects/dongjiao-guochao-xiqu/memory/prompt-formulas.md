# Prompt Formulas

## 2026-05-08 | Guochao Xiqu Character Three-View Sheet

Use this when generating standalone styling-store character designs.

Core structure:

```text
Character design sheet for one standalone young Chinese Guochao xiqu / Chinese opera inspired styling character.
Strict 16:9 horizontal image. Full body THREE VIEWS of the same character and same outfit: front view, side/profile view, back view, arranged left-to-right.
Show full head-to-toe silhouette, hairstyle/headwear, sleeves, waist construction, hem length, trousers or skirt structure, shoes, and back details.
This is a fashion costume concept sheet for a styling experience store, not a stage photo and not a scene.
```

Identity anchors:

```text
Keep traditional opera headwear silhouette as foundation: fengguan, shuai helmet, huadan bead flowers, wudan lingzi, pearl tassels, black forehead hair patches, red pom-poms, enamel side ornaments, cloud motifs.
Makeup is simplified modern beauty makeup: natural translucent skin, fine eyeliner, soft blush, clean red/peach lip, no white painted opera face.
```

Fashion direction:

```text
Modern Chinese Guochao for ages 16-35, wearable, photogenic, boutique styling experience, refined fashion illustration / photorealistic concept art.
Use pankou buttons, small cloud collar, cloud shoulder, embroidered gauze, detachable water-sleeve panels, pearl waist tassels, clean boots or fashion sneakers.
```

Negative constraints:

```text
Do NOT use mamian skirt. Do NOT use stereotypical long new-Chinese robe.
No gothic, no cyberpunk, no techwear armor, no black leather dominance, no tactical harness, no samurai, no kimono, no bridal gown, no cheap cosplay, no text, no watermark.
```

## 2026-05-08 | Body-Friendly But Normal-Body Model Formula

Use when designing more covering, inclusive garments without changing the model's body type.

```text
CRITICAL BODY REQUIREMENT: keep the person in normal young fashion-model proportions like the previous accepted design sheets. Do NOT make the character visibly overweight, bulky, heavy, older, or plus-size. The model should look 16-35, fresh, average-to-slim body, normal arms and face, elegant posture. The CLOTHING is size-inclusive and forgiving, but the person does not become fat.

Fit requirement for real customers: no exposed navel, no exposed belly, no cropped top, no bare waist, no tight bodycon. Use mid-length tops, hip-covering jackets, long cloud-collar overlays, soft A-line lines, relaxed wide-leg or straight trousers, knee-length layered skirt-over-pants, vertical embroidery panels, soft draping that covers belly and hips.
```

## 2026-05-08 | Fashion Background For Review Sheets

Use when the subject is already approved and only background needs a cleaner display context.

```text
Fashion background: clean contemporary fashion studio background, cool white and very light gray, subtle editorial gradient, soft floor shadow.
Do NOT use yellow, beige, warm parchment, palace background, stage set, industrial scene, text labels, captions, watermark, logo, or extra people.
```

Note: In this project the user later accepted keeping the current background for batch output. Use this formula only when the user specifically asks for a fashion-background refresh.
